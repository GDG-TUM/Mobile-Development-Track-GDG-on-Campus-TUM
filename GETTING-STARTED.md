# Getting Started

This guide helps you set up your environment for the Mobile Development Track.

## Required tools

- Android Studio
- JDK 17 or newer
- Android SDK
- Git and GitHub
- A device or emulator for testing

## 1. Install Android Studio

Download and install Android Studio from the official Android developer site.

During setup, make sure you install:

- Android SDK
- Android SDK Platform Tools
- Android Emulator
- Intel or Apple virtualization support if required

## 2. Create a project

Open Android Studio and create a new project using:

- Empty Activity or Empty Compose Activity
- Kotlin as the language
- Minimum SDK version that matches your target users

## 3. Verify your environment

Before proceeding, confirm that:

- Android Studio opens without errors
- The emulator can launch
- You can run a sample app successfully

## 4. Set up Git and GitHub

- Create or sign in to your GitHub account
- Install Git if needed
- Configure your name and email
- Clone the repo and start working in a branch

## 5. Recommended learning flow

Follow the track in order:

1. Start with the weekly roadmap
2. Learn fundamentals before advanced topics
3. Build small apps before combining features
4. Keep project iterations small and testable
5. Present your work clearly at the end of each milestone

## 6. Recommended resources

- Android Developer Documentation
- Kotlin Documentation
- Jetpack Compose Documentation
- Firebase Documentation
- Material Design Guidelines

## 7. Common setup issues

- Emulator not starting: check virtualization support and device profile
- SDK missing: install the required Android SDK packages
- Gradle sync errors: update Android Studio and confirm JDK version

## 8. Next steps

Once your environment is working, begin with the first week in the roadmap and keep building forward.
