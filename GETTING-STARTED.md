# Getting Started

[← Back to Mobile Development Track home](../README.md)

## Before your first session

Follow this checklist so you are ready to build from day one.

### 1. Join the GitHub organization

- [ ] You have a GitHub account (if not, [sign up here](https://github.com/signup))
- [ ] You have been added to [GDG-TUM](https://github.com/GDG-TUM)
- [ ] You can see this repo in your organization view

**Need an invite?** Ask in the track channel or contact the track lead.

### 2. Install Android Studio

- [ ] Download [Android Studio](https://developer.android.com/studio) (latest version)
- [ ] Run the installer and follow the setup wizard
- [ ] Accept the licenses when prompted
- [ ] Open Android Studio and wait for the initial setup to complete (~5–10 minutes)

**Stuck?** Check the [official setup guide](https://developer.android.com/studio/install) or ask in the track channel.

### 3. Set up Git and GitHub

- [ ] Install [Git](https://git-scm.com/)
- [ ] Tell Git your name: `git config --global user.name "Your Name"`
- [ ] Tell Git your email: `git config --global user.email "your.email@example.com"`
- [ ] Create an SSH key: `ssh-keygen -t ed25519` (press Enter for all prompts)
- [ ] Add your SSH key to GitHub: [GitHub SSH setup guide](https://docs.github.com/en/authentication/connecting-to-github-with-ssh)

**Why SSH?** It is safer and easier than typing your password every time.

### 4. Test your setup

- [ ] Clone this repo: `git clone git@github.com:GDG-TUM/Mobile-Development-Track-GDG-on-Campus-TUM.git`
- [ ] You can see the files on your laptop
- [ ] Open Android Studio and create a new "Empty Activity" project
- [ ] Run it on the emulator or a device—you should see "Hello Android!"

### 5. Add your profile

- [ ] Go to the [members/](../members/) folder
- [ ] Create a file named `your-name.md`
- [ ] Add your name, interests, and learning goals
- [ ] Open a pull request with your profile

**Example:**

```markdown
# Your Name

- Track role: Member
- Interest: Android, Kotlin, Firebase
- GitHub: @yourusername
- Goals: Learn Compose, build a study app, ship a working prototype
```

### 6. You are ready

- [ ] You can create a new Android project
- [ ] You have cloned this repo
- [ ] Your profile is in the members folder
- [ ] You know how to ask for help in the track channel

**Questions?** Open an issue or ask in the track channel. No question is too basic.

## Troubleshooting

### "Android Studio won't start."

- Restart your laptop
- Check that you have at least 8 GB of RAM and 5 GB of disk space
- Try re-downloading Android Studio

### "Git clone fails."

- Check that your SSH key is added to GitHub
- Try `git clone https://github.com/GDG-TUM/Mobile-Development-Track-GDG-on-Campus-TUM.git` instead (HTTPS, not SSH)

### "Emulator is very slow."

- Use a physical device if you have one
- Give Android Studio more RAM in settings
- Try the lightweight "Pixel 4a" device instead of a larger one

### Still stuck?

Ask in the track channel with a screenshot of the error. We are here to help.
