# Maintainers Guide

[← Back to docs](README.md)

## For track leads and helpers

### Launch checklist
- [ ] Track repository created and named correctly
- [ ] README and folder structure in place
- [ ] GitHub organization members added
- [ ] Issue templates created
- [ ] Pull request template created
- [ ] Chapter board linked
- [ ] First session scheduled and announced

### Weekly operations
- [ ] Run the session (90 minutes)
- [ ] Push notes and code to repo
- [ ] Create next week's issue
- [ ] Review pull requests from members
- [ ] Answer questions in the help channel
- [ ] Update the board with progress

### Monthly check-in
- [ ] Meet with core team members
- [ ] Review project progress
- [ ] Adjust roadmap if needed
- [ ] Celebrate wins
- [ ] Address blockers

### Semester handover
- [ ] Write a retrospective
- [ ] Document lessons learned
- [ ] Update this guide with new insights
- [ ] Introduce the next track lead
- [ ] Archive completed projects

### Managing pull requests
- Be kind and specific
- Celebrate good work
- Suggest improvements, don't demand
- Merge small, focused changes often
- Label issues clearly

### Keeping the repo healthy
- Review open issues monthly
- Update links and resources as they change
- Help members with their first pull request
- Recognize contributors
