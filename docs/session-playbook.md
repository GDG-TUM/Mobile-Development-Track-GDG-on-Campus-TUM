# Session Playbook

[← Back to docs](README.md)

## Running a great session

### Before the session
- [ ] Prepare the slide deck or demo
- [ ] Test all code examples
- [ ] Set up the GitHub issue for the session
- [ ] Post date and time in the chapter channel

### Session outline (90 minutes)

| Time | Activity | Notes |
|------|----------|-------|
| 0-5 min | Welcome | Why this week matters |
| 5-15 min | Concept | Short explanation, 10 minutes max |
| 15-60 min | Build together | Live coding, debugging, asking questions |
| 60-80 min | Challenge | Small independent task |
| 80-90 min | Wrap up | Questions, assignment, next week preview |

### Guiding principles
- **Live code.** Don't just show slides.
- **Make mistakes.** Debugging is learning.
- **Ask questions.** Invite participation.
- **Go slow.** It is better to cover less deeply than rush.
- **Help peers.** Create a helping culture.

### After the session
- [ ] Push notes and code to the repo
- [ ] Note any questions or blockers
- [ ] Post a session feedback form
- [ ] Celebrate what members built
