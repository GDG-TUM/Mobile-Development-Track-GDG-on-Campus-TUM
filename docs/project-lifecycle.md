# Project Lifecycle

[← Back to docs](README.md)

## From idea to demo day

Every capstone project moves through these stages:

### 1. Idea (Week 8, before sprint)
- Identify a real problem
- Sketch the app concept
- List 3-5 core features
- Get feedback from peers

### 2. Planning (Week 8, sprint start)
- Create a GitHub repo
- Write a README with the problem and solution
- Break features into tasks
- Set up a basic project board

### 3. Build (Weeks 8-9)
- Commit small, focused changes
- Test on devices and emulators
- Ask for help when stuck
- Iterate based on feedback

### 4. Polish (End of Week 9)
- Fix critical bugs
- Improve UI clarity
- Add helpful error messages
- Test the happy path multiple times

### 5. Demo (Week 9)
- Prepare a 3-5 minute demo
- Practice the pitch twice
- Film a backup recording
- Write a short reflection

### 6. Share (After demo day)
- Push final code to GitHub
- Write what you learned
- Help others with similar ideas
- Plan improvements for next semester

## Checkpoints
- **Week 7 end:** Project proposal approved
- **Week 8 end:** Functional prototype
- **Week 9 start:** Demo-ready version
- **Week 9 end:** Presented and documented
