# GDG on Campus - Mobile Development Track: 9-Week Calendar

This document organizes the 9-week mobile development learning plan into a practical schedule for a GDG on Campus track.

## Program Goals

- Introduce participants to mobile app development
- Build confidence with Android and Google mobile tools
- Help students create a working capstone project
- Encourage community learning and technical leadership

## Weekly Schedule

### Week 1 – Foundations
- Introduction to mobile development
- Tools and environment setup (Android Studio, Kotlin)
- Basic Kotlin syntax
- First app and project walkthrough

### Week 2 – UI Fundamentals
- Layouts and views
- Styling and Material components
- Building interactive screens
- Simple app prototype

### Week 3 – Navigation and State
- Activities/Fragments and navigation patterns
- State management
- ViewModel and lifecycle basics
- Multi-screen app flows

### Week 4 – Data and APIs
- Local data storage
- SharedPreferences and Room
- Networking and API requests
- Parsing JSON data

### Week 5 – Firebase Integration
- Firebase setup and SDK integration
- Authentication
- Firestore and cloud storage
- Real-time features

### Week 6 – App Architecture and Testing
- MVVM architecture
- Repository patterns
- Hilt or dependency injection basics
- Unit tests and UI tests

### Week 7 – Advanced Features
- Notifications
- Camera and media
- Location and maps
- Performance and accessibility

### Week 8 – Capstone Development
- Final project ideation
- Feature planning and sprint execution
- UI refinement and integration
- Mid-project review

### Week 9 – Launch and Showcase
- Final polishing
- Bug fixing and optimization
- Demo preparation
- Final presentation and reflection

## Suggested Deliverables

- Weekly coding tasks
- Mini assignments after each week
- Mid-track review
- Final mobile app demo
- Reflection notes for continued learning

## Recommended Stack

- Kotlin
- Android Studio
- Jetpack Compose or XML UI
- Firebase
- Git and GitHub

## Optional Add-ons

- Flutter track extension
- Kotlin Multiplatform introduction
- Google Play Console publishing overview
- Community leadership and session hosting guidance

This calendar can be adapted to beginner, intermediate, or lead-focused GDG sessions.
