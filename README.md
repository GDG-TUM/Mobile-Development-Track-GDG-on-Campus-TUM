# GDG Mobile Development Track

A 9-week mobile development learning track for GDG on Campus members, designed to help students and developers build practical Android and Google mobile skills.

This repository turns the provided 9-week calendar into a structured learning path, starter resources, and project-based milestones.

## Overview

This track focuses on:

- Mobile app fundamentals and modern Android development
- Kotlin and Jetpack Compose
- Firebase and cloud-backed app features
- App architecture, testing, and deployment
- Capstone project planning and presentation

## 9-Week Calendar

### Week 1: Mobile Development Foundations
- Introduction to mobile ecosystems
- Android architecture overview
- Kotlin basics: variables, functions, classes, null safety
- Setting up Android Studio and the Android SDK
- First app: Hello World + basic UI

Resources:
- Android Kotlin basics
- Android developer documentation
- Kotlin official docs

### Week 2: UI Design and Layouts
- XML vs Compose overview
- Layouts: LinearLayout, ConstraintLayout, Column/Row
- Text, buttons, images, and styling
- Material Design fundamentals
- Build a simple form app

Resources:
- Jetpack Compose docs
- Material Design

### Week 3: App Logic and Navigation
- State and events
- ViewModel and lifecycle
- Navigation between screens
- Passing data between screens
- Create a multi-screen app

Resources:
- ViewModel documentation
- Navigation in Compose

### Week 4: Data Handling and Persistence
- Working with local storage
- SharedPreferences
- Room database fundamentals
- Networking basics with Retrofit or Ktor
- JSON parsing and API consumption

Resources:
- Room database
- Retrofit guide
- Kotlin coroutines

### Week 5: Firebase and Backend Integration
- Firebase project setup
- Authentication and Firestore
- Cloud Storage basics
- Real-time data updates
- Build a collaborative or user-based app

Resources:
- Firebase for Android
- Firestore docs
- Firebase Authentication

### Week 6: Architecture and Quality
- MVVM architecture
- Repository pattern
- Dependency injection basics
- Testing fundamentals
- Unit and UI testing

Resources:
- Android architecture guide
- Testing docs
- Hilt docs

### Week 7: Advanced Mobile Features
- Background work and notifications
- Camera and media integrations
- Maps and location services
- Performance optimization
- Accessibility basics

Resources:
- Android notifications
- Location and maps docs
- Accessibility docs

### Week 8: Capstone Project Sprint
- Define app idea and target user
- Plan features, screens, and data model
- Integrate Firebase or backend features
- Build and refine app prototype
- Prepare project demo

Deliverables:
- Functional prototype
- UI walkthrough
- Architecture explanation

### Week 9: Launch, Reflection, and Community Leadership
- App polishing and bug fixing
- Prepare release build and APK/AAB
- Google Play basics and app publishing workflow
- Presentation and reflection
- Next-step roadmap for learning and mentoring

Deliverables:
- Final presentation
- Demo app
- Learning reflection and improvement plan

## Suggested Project Ideas

- Event app for GDG chapters
- Campus marketplace app
- Study planner
- Fitness tracker
- Food ordering prototype
- Community board app

## Recommended Tools

- Android Studio
- Kotlin
- Firebase Console
- Git and GitHub
- Postman
- Figma (optional)

## Track Outcomes

By the end of this program, participants should be able to:

- Build simple Android apps with modern UI patterns
- Work with local and remote data
- Connect apps to Firebase services
- Apply architecture and testing principles
- Present a complete mobile app project
- Contribute as a future mobile lead in a tech community
