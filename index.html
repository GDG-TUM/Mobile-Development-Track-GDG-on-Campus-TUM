      Questions people ask first.

      Do I need to know mobile development already?

      No. If you can use a laptop, install software and stay curious, you belong here.

      I missed a session. Am I behind?

      No. Open that week's folder in the weekly sessions and work through it. Everything is in the repo, and you can ask for help in the track channel.

      I have never used GitHub.

      That is fine. Keep your changes small and readable, and ask if you get stuck. GitHub Skills has short interactive lessons.

      How do I get involved?

      Join the GDG-TUM GitHub organization, add your plan in member-roadmaps, set up your tools, start with Week 1, and open a pull request when you add notes, resources or improvements.

      Can I add my own notes and examples?

      Yes, that is the idea. Read CONTRIBUTING.md first, then send a pull request with resources, workshop notes, assignments or project examples.

      What do the roles mean?

      The track lead plans the semester and runs sessions. Maintainers review contributions. Invited mentors help teams with debugging, product thinking and demos. Members attend, complete challenges, build projects and help each other.

      How is the track doing?

      We look for at least one app prototype per member, projects shown at demo day, public GitHub repos and pull requests, and feedback after each session. Tell us how we are doing.

      Ready to build your first app?

      Be kind, ask questions, and ship small things often. We follow our Code of Conduct.
