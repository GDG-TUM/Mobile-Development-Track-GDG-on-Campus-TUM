# Contributing to the Mobile Development Track

Thanks for helping improve the Mobile Development Track for GDG on Campus TUM.

We welcome contributions from students, mentors, and community members.

## How to contribute

You can contribute by:

- improving the learning roadmap
- adding session notes or workshop resources
- proposing project ideas
- fixing typos and broken links
- improving setup instructions
- adding examples, code snippets, and demos

## Workflow

1. Open an issue for larger changes or new ideas
2. Create a branch with a clear, short name
3. Make a focused change
4. Open a pull request with a short description
5. Ask for review from maintainers or peers

## Writing style

- Keep docs clear, concise, and beginner-friendly
- Use inclusive language
- Prefer practical, action-oriented instructions
- Include examples where helpful

## Pull request guidance

A good pull request should:

- explain what changed and why
- be limited to one topic or improvement
- include relevant links or screenshots when useful
- be easy for others to review

## Code of conduct

Please keep discussions respectful and constructive. We are here to learn together.

If you are unsure about a change, ask in the issue tracker before making a large update.

## Questions

If you need help, open an issue or contact the track maintainers through the GDG-TUM organization.
