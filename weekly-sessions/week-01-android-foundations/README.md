# Week 1: Android Foundations

[← Back to weekly sessions](../README.md)

## Goals
- Understand how Android apps are structured
- Set up a working Android Studio environment
- Write simple Kotlin code
- Run a first app on an emulator or device

## Topics
- Android architecture overview
- Kotlin basics
- Activities and app lifecycle
- Running apps in Android Studio

## Challenge
Build a small app that shows a greeting message and a button that updates the text.
