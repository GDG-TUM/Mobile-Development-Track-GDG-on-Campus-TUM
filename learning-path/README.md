# 🧭 Learning Path

This track is built to move from beginner-friendly foundations into real app building.

| Stage | Topic | Outcome | Read |
|-------|-------|---------|------|
| 1 | Foundations | Understand the Android stack and Kotlin basics | [01-foundations.md](01-foundations.md) |
| 2 | UI and layouts | Build modern interfaces with Compose | [02-ui-and-layouts.md](02-ui-and-layouts.md) |
| 3 | App logic | Create multi-screen flows and screen state | [03-app-logic.md](03-app-logic.md) |
| 4 | Data and persistence | Save and load meaningful app data | [04-data-and-persistence.md](04-data-and-persistence.md) |
| 5 | Firebase | Connect apps to cloud-powered features | [05-firebase.md](05-firebase.md) |
| 6 | Ship it | Apply architecture, testing and demo quality | [06-ship-it.md](06-ship-it.md) |

## How to use this path
1. Read the stage page, then do the matching weekly session.
2. Finish the challenge before moving on.
3. Ask for help early if something is unclear.
4. Add notes or improvements back to the repo.
