## How to use this path

1. **Read the stage page** to understand topics and outcomes
2. **Do the matching weekly session** to build hands-on skills
3. **Finish the challenge** before moving to the next stage
4. **Ask for help early** if something is unclear
5. **Add notes or improvements** back to the repo—your questions help the next cohort

## Learning principles

- **Build real things, not exercises.** Every stage creates something you can show or use.
- **Understand before memorizing.** We focus on why code works, not just patterns.
- **Ship early and often.** A finished small app beats an abandoned big idea.
- **Learn in public.** Your code, notes, and questions belong on GitHub.
- **Fail small.** Test early and understand errors before they become big problems.

## What you need

- A laptop with Android Studio installed
- Curiosity and patience
- A GitHub account (free)
- About 8–10 hours per week for sessions and challenges
- Willingness to debug and ask questions

## After you finish

Your capstone project is proof of skill. Keep building on it, contribute to open source, or mentor newer members. The best learning happens when you teach.
