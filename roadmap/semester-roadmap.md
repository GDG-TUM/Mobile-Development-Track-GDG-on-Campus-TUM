# Mobile Development Track roadmap

[← Back to Mobile Development Track home](../README.md)

## Semester plan

### Phase 1: Foundations and product thinking

| Week | Focus | Outcome |
|---|---|---|
| 1 | Android foundations | Set up the environment and understand the app stack |
| 2 | UI and Compose | Build clean, usable screens |
| 3 | App logic and navigation | Design flows and state handling |
| 4 | Data and persistence | Save and retrieve useful data |
| 5 | Firebase | Add cloud-powered features |
| 6 | Architecture and quality | Apply cleaner patterns and testing habits |

### Phase 2: Build and ship

| Week | Focus | Outcome |
|---|---|---|
| 7 | Advanced features | Notifications, location, media, accessibility |
| 8 | Capstone sprint | Build a complete prototype |
| 9 | Launch and reflection | Demo, polish, and share lessons |

## How the roadmap is designed

- Start with understanding and clarity
- Move quickly into building small features
- Add real-world complexity only when foundations are stable
- End with a product-oriented capstone that can be shown to others

## Recommended rhythm

- One session per week
- Small hands-on challenge after each concept
- A small public artifact or note in the repo after each milestone
- A final capstone presentation at the end of the semester
